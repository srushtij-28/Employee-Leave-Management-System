# Employee Leave Management System

A simple multi-file Python application for managing employees and their leave requests.

## Features

- Add employees
- View employees
- Search employees
- Delete employees
- Track leave balance
- Apply for leave
- View leave requests
- Approve leave
- Reject leave
- View employee leave history
- Automatic leave ID generation
- JSON data storage
- Modular Python structure

## Technologies

- Python
- JSON
- File Handling
- Datetime
- Python Modules
